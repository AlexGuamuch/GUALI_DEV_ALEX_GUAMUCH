# El ciclo for

Un ciclo repite instrucciones sin que tengas que escribirlas muchas veces.

```java
void main() {
    for (int i = 1; i <= 10; i++) {
        IO.println("7 x " + i + " = " + (7 * i));
    }
}
```

## Las tres partes del for

- `int i = 1`: dónde empieza el contador.
- `i <= 10`: mientras se cumpla, el ciclo sigue.
- `i++`: cuánto avanza en cada vuelta.
