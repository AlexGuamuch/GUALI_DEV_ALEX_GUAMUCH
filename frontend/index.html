    Ayuda

    Cómo practicar con Guali, paso a paso.

    Paso 1Abre una lecciónMenú Lecciones → Abrir lección. Sus instrucciones aparecen en el panel izquierdo.
    Paso 2Escribe el código a manoCopia el ejemplo tecleándolo en el editor. Pegar está deshabilitado a propósito: escribir te ayuda a memorizar la sintaxis.
    Paso 3Compila y lee la consolaSi hay errores, la consola te dice la línea y el motivo. Corrígelo y vuelve a compilar.
    Paso 4Ejecuta tu programaEjecutar se habilita cuando la última compilación no tuvo errores. Revisa tu progreso en Historial.
    ¿Necesito crear una cuenta?
    No. Los estudiantes usan Guali sin registrarse. Tu historial y tus preferencias se guardan para este navegador.
    ¿Puedo leer datos con Scanner?
    No. El programa no recibe entrada del teclado mientras se ejecuta. Escribe los valores directamente en el código.
    ¿Cuánto tiempo puede tardar mi programa?
    Hasta 5 segundos. Si se pasa, por ejemplo por un ciclo infinito, se detiene y la consola te lo indica.
    ¿Qué versión de Java se usa?
    Java 25. Puedes escribir la forma compacta void main() { IO.println("Hola"); } o una clase completa con public static void main.
    Compilar con errorReconocer erroresPresiona Compilar y consigue que el compilador reporte al menos un error. Aprendes a leer sus mensajes.
    Compilar exitosoSintaxis correctaPresiona Compilar y consigue 0 errores.
    Ejecutar con errorErrores en ejecuciónCompila sin errores y ejecuta hasta que el programa falle, por ejemplo con una división entre cero.
    Ejecutar exitosoCiclo completoEscribe, compila y ejecuta hasta que el programa termine sin errores.

    Sube un .zip con una o más lecciones. Se guardan en la base de datos.

    lecciones.zip └── leccion-01-hola-mundo/ ├── leccion.md instrucciones en markdown ├── config.txt objetivo=EJECUTAR_EXITOSO └── imagen.png opcional

    Eliminar una lección

    La lección y sus imágenes se borran de la base de datos. El historial se conserva.
